# Homebrew Tap for podkit

[podkit](https://github.com/jvgomg/podkit) is a toolkit for syncing music collections to iPod devices.

## Install

```bash
brew install jvgomg/podkit/podkit
```

Or equivalently:

```bash
brew tap jvgomg/podkit
brew install podkit
```

FFmpeg is installed automatically as a dependency.

See the [main repository](https://github.com/jvgomg/podkit) for full documentation.
